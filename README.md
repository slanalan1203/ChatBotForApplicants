# ChatBotForApplicants

## 1. Контекст проекта  
### 1.1 Бизнес-задача  
-  Ускорение ответа операторов, уменьшение нагрузки на штат
-  Повышение доступности получения информации о поступлении
-  Сокращение числа ошибок(?)

### 1.2 Целевая аудитория и пользователи  
-  Абитуриенты
-  Родители абитуриентов
-  Сотрудники Высшей Школы Экономики для быстрого поиска нужной информации

### 1.3 Ограничения и допущения  
-  Чат-бот будет работать только в рамках домена поступления в университет
-  Система НЕ предназначена для юридический консультаций, только поиск информации из источников

## 2. Архитектура решения  
### 2.1 Общая схема  
-  используем принцип RAG
-  пользователь вводит вопрос, ищются релевантные куски в базе данных, генерируется человекочитаемый вывод

### 2.2 Хранилище знаний / документооборот  
-  PDF файлы с сайта Высшей Школы Экономики и РСОШ в статичном виде
-  Документооборот. Загруженные документы проходят через очистку от ненужной информации с помощью LLM с сохранением метаданных(название, URL, страница)
-  Обработанные документы преобразуются в векторные представления и сохраняются в соответствующей веткорной базе данных
